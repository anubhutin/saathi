# SAATHI

A self-contained, mobile-friendly SAATHI website.

## Open locally
1. Download and extract this repository ZIP.
2. Open `index.html` in a web browser.

## Put it in a Git repository
Create a new repository on GitHub, upload `index.html` and `README.md`, then enable GitHub Pages from the repository's Pages settings (deploy from the main branch and root folder).

The site is a single-file static website and does not require npm or a build step.
